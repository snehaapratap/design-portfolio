I’m Sneha, a solo freelancer based in Bengaluru. My background is in software and generative AI, and these studies show how I approach web interfaces and visual communication.

I use AI-assisted HTML, CSS, JavaScript and SVG, then check layout, content and browser behaviour manually. I’m interested in small, clearly scoped website and visual-layout assignments.

These are demonstration projects, not commissioned client work. Editable SVG layouts are prototypes; native Figma/Adobe deliverables and print production have not been validated. The FORME prototype includes an attributed Unsplash photograph.
