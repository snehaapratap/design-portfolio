Approach

Start with the task.
Keep the design editable.

These studies use original geometric layouts, editable text and named vector groups. They contain no third-party photographs, logos, external media or embedded font files.

Local checks covered rendered layout, text bounds and changes to text, colour and object position. The SVG files use system-font fallbacks. Adobe-app editing, native template formats, print colour and bleed have not yet been validated.

The invoice, charts and timelines are visual layouts with manual sample data; they do not calculate totals or connect to live data.

This is a prototype portfolio. These designs are not approved Adobe Stock templates or available for purchase here.
